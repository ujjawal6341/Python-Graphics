Python 2D Art & Image Creation Project:

This repository contains my learning and experiments with Python libraries focused on 2D graphics, artistic designs, and image creation.

The goal of this project is to explore how Python can be used to create visual art, patterns, and images programmatically.

🚀 Features
🎨 Create 2D artistic patterns
🖼️ Generate images using code
📐 Work with shapes, colors, and coordinates
🔁 Practice loops, functions, and logic in visual form
💡 Beginner-friendly implementations
🧰 Libraries Used

This project explores multiple Python libraries:

turtle → For drawing shapes and patterns
matplotlib → For plotting and basic visuals
Pillow (PIL) → For image creation and editing
pygame → For advanced graphics and animations
numpy → For numerical operations in image processing
