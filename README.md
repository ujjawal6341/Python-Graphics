# 🎨 Python 2D Art & Generative Graphics

> **Turning Python code, mathematics, and algorithms into visual art.**

A collection of **Python-based 2D graphics, generative art, image-processing experiments, animations, and creative coding projects**.

This repository explores how programming can move beyond traditional applications and become a medium for **visual creativity**. Using libraries such as `Turtle`, `Matplotlib`, `Pillow`, `Pygame`, and `NumPy`, the project transforms mathematical concepts, algorithms, coordinates, pixels, and randomness into digital artwork.

Whether you're learning Python, experimenting with computer graphics, exploring generative art, or simply curious about what happens when code starts drawing pictures, this repository is designed to provide practical and easy-to-understand examples.

* 🎨 **Generative Art** - Create algorithmically generated patterns and artwork.
* 🖼️ **Programmatic Image Creation** - Generate images entirely through Python code.

# 🚀 Getting Started

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/Python-2D-Art.git
cd Python-2D-Art
```

## 2️⃣ Create a Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

If a `requirements.txt` file is not available, install the main libraries manually:

```bash
pip install matplotlib pillow pygame numpy
```

> `turtle` is included with most standard Python installations and normally does not require a separate installation.

---

# ▶️ Running the Projects

Navigate to the experiment you want to run and execute the Python file:

```bash
python filename.py
```

For example:

```bash
python turtle/mandala.py
```

or:

```bash
python pillow/image_generation.py
```

Each experiment focuses on a specific graphical concept and can be modified to create your own designs.

# 🎨 What Can Be Created?

This repository explores many different forms of programmatic artwork.

### 🌀 Geometric Patterns

Generate complex designs from simple geometric primitives.

```text
Triangle → Rotation → Repetition → Pattern
```

A few lines of mathematical logic can produce surprisingly complex visual structures.

---

### 🌸 Mandala & Symmetrical Art

Use rotational symmetry to generate intricate circular patterns.

```text
        ✦
    ✦       ✦
  ✦     ●     ✦
    ✦       ✦
        ✦
```

The artwork is generated through coordinates, angles, repetition, and transformations.

Mathematical equations can become visual structures.

Examples include:

# 📸 Generated Artwork

The `output/` directory contains images and artwork generated by the Python programs.

A typical workflow looks like:

```text
Python Code
     ↓
Mathematical Logic
     ↓
Coordinates / Pixels
     ↓
Rendering
     ↓
Generated Artwork
```

This makes it possible to reproduce artwork, modify the underlying algorithm, and generate completely new variations.
